## 🌟 What is Agentic OS?

**Agentic OS** is a modular, TypeScript/Node.js-powered operating environment designed for autonomous AI agents. Built with privacy and local-first execution in mind, it combines heavy-duty LLM inference, persistent vector/JSON memory, proactive background sweeps, and native GUI control (*OpenMausBot*) into a single lightweight framework.

## 🚀 Quick Start (Zero Friction)

Get the engine running locally in under 30 seconds with a single command:

```bash
# 1. Clone the repository
git clone [https://github.com/ElinRingkvist/agentos_chatbot.git](https://github.com/ElinRingkvist/agentos_chatbot.git)
cd agentos_chatbot

# 2. Install dependencies
npm install

# 3. Launch the engine
npm start
