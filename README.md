# Persistent Agentic OS Architecture 🤖🌍⚡

> **An open-core, multi-language, offline-first agent OS with HuggingFace LLM inference, OpenMausBot GUI automation, and live web search integration.**

---

## 🔥 Key Capabilities

- **🖱️ OpenMausBot GUI Automation:** Native OS-level mouse movement, keystrokes, and GUI interaction.
- **🤗 Hugging Face Integration:** Run open-source LLMs (Llama 3, Qwen, Phi-3) offline on device with zero API fees.
- **🌐 Live Web Search & Browsing:** Multi-engine web search (Google, Brave, Edge, Safari) for real-time information retrieval.
- **🗣️ Multi-Language Support (i18n):** Native support for Swedish, English, Spanish, French, German, and more.
- **🧠 Persistent Compounding Memory:** Long-term memory context storage across tasks, chats, and codebases.
- **🔄 Proactive Heartbeat Engine:** Scans files, inboxes, and repos while you sleep, delivering customized Morning Digests.
- **🔒 Sandboxed OS Execution:** Native local access with interactive Human-in-the-Loop approval cards.
